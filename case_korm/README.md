# Корм для людей — лендинг и питч-дек

Два материала по FoodTech-концепту «Корм для людей»: прототип предзапускового сайта
и презентация для инвестора. Оба собраны строго по `PROJECT_BRIEF_RU.md`.

## Что здесь лежит

| Файл | Что это |
|---|---|
| `index.html` | **Сайт**, готовый к публикации: одностраничник с вшитыми изображениями (2 МБ, ничего не грузится извне) |
| `site.src.html` | исходник страницы с метками `{{IMG_*}}` вместо картинок — правим его, а не `index.html` |
| `build_site.py` | подставляет изображения в исходник и собирает `index.html` |
| `Корм для людей — питч для инвестора.pptx` | **презентация**, 16 слайдов, 16:9 |
| `Корм для людей — питч для инвестора.pdf` | та же презентация для быстрого просмотра |
| `build_deck.js` | генератор презентации (pptxgenjs) |
| `assets/`, `deck_img/` | пять концептов упаковки: исходные webp и jpg для презентации |
| `PROJECT_BRIEF_RU.md` | исходный бриф проекта |

Пересборка:

```bash
pip install openpyxl pillow && npm install          # один раз
python3 build_site.py                                # сайт
node build_deck.js                                   # презентация
```

## Сайт

Живая версия опубликована как артефакт: <https://claude.ai/code/artifact/e8368e10-2811-466e-bcc4-1c28deb2eaa5>

**Структура** — ровно по брифу: шапка → первый экран → проблема → пять форматов →
польза → блок для офисов → стадия проекта → FAQ → финальный призыв → подвал.

**Оформление.** Тёплая бумага `#F6F3EB`, чёрная типографика, жёлтый `#FFD600` как
единственный яркий акцент; зелёный `#526333` и оранжевый `#DE702D` закреплены за
способами употребления. Шрифты: Unbounded (заголовки), Golos Text (текст),
JetBrains Mono (технические подписи). Тёмной темы намеренно нет — бренд светлый
и тёплый, страница красится явно и одинаково у всех.

**Форматы показаны крупно**: пять полноширинных блоков с чередованием стороны
картинки, на телефоне — по одному в колонку. Упаковка не обрезается
(`object-fit: contain`), пропорции исходных 1254×1254 сохранены.

**Способ употребления — главный структурный элемент.** У каждого формата видимый
цветной чип: «Без приготовления», «Нужна вода», «Нужен кипяток». Общая формулировка
«всё готово без воды» не используется — она неверна для порошка и лапши.

**Честность по брифу.** Наверху постоянная полоса «Проект на стадии разработки.
На изображениях — концепты продукта и упаковки». Ни одна рекламная надпись с макетов
(белок, витамины, «100 % натурально», срок годности, знаки ™ и ®) не перенесена в текст
страницы. Нет выдуманных контактов, реквизитов, отзывов, партнёров, цен и дат.
Шаг «интерес покупателей» подписан как текущий, остальные четыре — как предстоящие.

**Формы.** Две: частный покупатель (формат, один контакт на выбор — email или Telegram,
имя необязательно) и организация (организация, контактное лицо, рабочий email,
количество участников и комментарий — необязательно). Поля проверяются, ошибки
объяснены, повторное нажатие блокируется на время отправки, выбранный на карточке
формат подставляется автоматически, Esc и клик по подложке закрывают окно.

Приём заявок **работает в демонстрационном режиме**: это написано прямо в форме,
а сообщение после отправки честно говорит, что данные никуда не ушли. Точка
подключения — константа `SUBMIT_ENDPOINT` в скрипте страницы: подставьте URL своего
обработчика, и форма начнёт отправлять по-настоящему (делать это нужно там, где
страница размещена обычным html-файлом: в опубликованном артефакте внешние запросы
блокируются политикой безопасности). Событие успешной заявки пишется только при
подтверждённой доставке; выбор формата хранится в браузере и заявкой не считается.

Внутренние события для будущей аналитики складываются в `window.kdlEvents`:
`format_view`, `format_pick`, `form_open`, `lead_submitted`, `org_submitted`.
Внешние счётчики не подключены.

## Питч-дек, 16 слайдов

Титул · Проблема · Решение · Пять форматов · Аудитория · Как устроено производство ·
Бизнес-модель · Чем зарабатываем · Конкурентное поле · Что есть и чего нет ·
Дорожная карта · **Запрос** · Что покупает каждый транш · Команда · Риски · Следующий шаг.

**Запрос построен на поэтапном финансировании:** 500 000 ₽ на первый шаг — проверку
спроса, дальше транши по потребности под достигнутый результат. Риск инвестора
ограничен размером одного транша, а не всей суммой; бюджеты шагов 2–4 честно помечены
как «уточняется после предыдущего шага», а не выдуманы.

**Чего в деке намеренно нет:** оценок объёма рынка, выдуманных сроков, имён команды
и партнёров, отзывов, результатов исследований и характеристик продукта. Ориентир
«4–6 месяцев до небольшого пилота» назван рабочей гипотезой. Слайд «Что уже есть
и чего пока нет» специально вынесен в середину — он держит весь остальной рассказ.

Команда показана шестью ролями с указанием шага, на котором роль появляется:
конкретные люди не выдуманы, потому что их нет в брифе.

## Перед публичным запуском

Это прототип. До реального сбора контактов нужно: подключить обработчик заявок,
подготовить документы и согласие на обработку персональных данных, обновить макеты
упаковки, убрав неподтверждённые заявления, и заменить концепты на фотографии
настоящего продукта.
